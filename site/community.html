Community

Let's build it together.

Sonora is meant to grow with the people who make music with it. You don't need to write code to help: trying it and telling us what happened is one of the most useful things you can do.

Bug reports

A good bug report gets fixed fast.

Open an issue on GitHub Issues. First search to see whether someone already reported it; if so, add what you know there.

Please don't attach projects or samples you don't have the right to share. A small project made just to show the problem is ideal.

Please include

  • Your Sonora version (shown in Settings › Updates) and your macOS, Windows or Linux version.
  • What you did, step by step, what you expected, and what happened instead.
  • Whether it happens every time.
  • For sound problems: which devices and plug-ins are on the track.
  • For crashes: the crash report, if your system shows one.
  • A screenshot or a short screen recording, if it helps.

Code

Contribute on GitHub

Sonora is C++20 with JUCE and Skia. Start with the README and the docs folder in the repository, then pick an issue or open a discussion about what you'd like to work on. Contributions are released under the AGPL-3.0-or-later.

How we talk to each other

Be kind. We're all here for the music.

People of every level are welcome, from first-time producers to seasoned engineers. Be patient, assume good intent, and critique ideas, never people. Harassment of any kind isn't tolerated.
