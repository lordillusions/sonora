# ADR 0002 — Skia (Ganesh/Metal) for the UI

**Status:** accepted (2026-10-13)

## Context
Sonora aims for Live 12's look & feel, using the same graphics library if possible. Live
draws its UI with Skia on Metal/OpenGL.

## Decision
- Use **Skia m144**, prebuilt by JetBrains skia-pack (`Skia-m144-e2e6623374-4-macos-Release-arm64.zip`),
  unpacked to `third_party/skia`. Ganesh backend on **Metal**; CPU raster fallback (`SONORA_RASTER=1`)
  and for off-screen snapshots.
- Compile definitions must match the prebuilt: `SK_RELEASE SK_GANESH SK_METAL SK_GL SK_BUILD_FOR_MAC`
  (`cmake/Skia.cmake`). A mismatch causes memory-corruption-like crashes.
- Own widget toolkit on top (ADR 0004).

## Consequences
- arm64 only (the prebuilt). Intel/Windows would need another prebuilt or building Skia with GN.
- Text uses CoreText through `SkFontMgr_New_CoreText`.
- Plugin editors stay native JUCE windows.
